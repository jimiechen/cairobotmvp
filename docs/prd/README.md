本目录包含 CaiRobot MVP 项目的产品需求文档。

| PRD-01 | 核心用户流程 | 待完成 | P0 | 定义主要用户流程与用例 |

## PRD 编写规范

每个 PRD 必须包含：

- 背景
- 目标
- 非目标
- 使用角色
- 核心流程
- 功能需求
- 非功能需求
- 验收标准
- 测试要求
- 截图/视频证据要求
- 风险
- 相关 Issue
- 相关 ADR
- 相关测试报告

## 状态定义

- 草稿：正在编写
- 评审中：待项目主控评审
- 已确认：已确认，可进入开发
- 已实现：已开发并测试通过
- 已废弃：不再使用
