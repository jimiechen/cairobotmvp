## 3. 决策

AI 服务使用 Python 独立实现，通过 gRPC 或 HTTP 与其他 Golang 服务通信。

## 4. 理由

（待补充）

## 5. 替代方案

- Golang + 机器学习库
- 其他语言（Rust、Java 等）

## 6. 后果

### 6.1 正面
- 机器学习生态最完善
- 开发效率高
- 社区支持好

### 6.2 负面
- 需要跨语言调用
- 性能略低于编译型语言
- 部署相对复杂

## 7. 约束

- AI 服务必须独立部署
- 与其他服务通过 gRPC 或 HTTP 通信
- 协议定义使用 Protobuf
- 不负责用户账号、权限等业务逻辑
