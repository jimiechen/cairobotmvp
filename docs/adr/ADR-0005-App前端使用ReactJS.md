## 3. 决策

## 6. 后果

### 6.1 正面
- 生态成熟
- 组件化开发
- 跨平台潜力（React Native）
- 社区支持好

### 6.2 负面
- 学习曲线
- 性能优化需要注意
- 原生 App 需要额外方案

## 7. 约束

- 前端代码统一放在 web/ 目录下
- 按系统分目录组织
- API 调用与 Protobuf 契约保持一致
- 关键流程必须有端到端测试
