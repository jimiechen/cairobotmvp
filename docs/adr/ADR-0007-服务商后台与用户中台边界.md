## 3. 决策

### 3.1 服务商后台系统职责
- 服务商账号管理
- 租户/渠道管理
- 设备批次管理
- 设备绑定与解绑管理
- 用户服务状态查看
- 售后工单管理
- 设备异常查看
- 服务套餐或权益管理
- 运营数据看板
- 系统配置管理

### 3.2 终端用户中台系统职责
- 家长账号管理
- 孩子档案管理
- 家庭空间管理
- 设备绑定关系
- 学习会话记录
- AI 使用记录
- 家长控制配置
- 通知与消息
- 用户隐私设置
- 订阅状态或服务权益

## 5. 替代方案

- 合并为一个系统
- 按其他维度划分

## 6. 后果

### 6.1 正面
- 职责清晰，各自独立演进
- 权限隔离更安全
- 部署和扩展更灵活

### 6.2 负面
- 部分功能可能有重复
- 需要处理跨系统的数据一致性

## 7. 约束

- 两个系统必须独立部署
- 通过内部 API 通信
- 数据隔离必须严格
- 权限必须严格控制

## 8. 后续待确认事项

- 设备绑定的具体流程
- 跨系统的数据同步机制
- 权限模型的具体设计
