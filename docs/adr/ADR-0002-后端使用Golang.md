## 3. 决策

以下后端服务使用 Golang 实现：
- 服务商后台服务
- 终端用户中台服务
- 开放平台服务
- 设备通信网关
- API 网关
- 认证服务
- 审计服务

## 5. 替代方案

- Java / Spring Boot
- Python / FastAPI
- Node.js / NestJS

## 6. 后果

### 6.1 正面
- 高性能
- 并发友好
- 编译型语言，类型安全
- 部署简单（单二进制文件）

### 6.2 负面
- 生态相对较小
- 泛型支持较新
- 学习曲线

## 7. 约束

- Golang 服务遵循 DDD 分层架构
- 目录结构遵循 services/[service_name]/ 规范
- 使用 Go Modules 管理依赖
- 单元测试覆盖率要求

## 8. 后续待确认事项

- 具体的 Web 框架（Gin、Echo 等）
- ORM 或数据库访问方式
- 配置管理方案
- 依赖注入方案
