# LLM Wiki

本目录包含 LLM Wiki，用于项目知识沉淀，方便后续 AI 助手快速理解项目。

## 目录

| 文件 | 说明 |
|---|---|
| LLM-WIKI.md | 主入口，包含项目总览和关键索引 |
| 项目上下文.md | 项目背景、目标、当前状态 |
| 工程规范索引.md | 工程规范的索引和摘要 |
| PRD索引.md | PRD 的索引和摘要 |
| ADR索引.md | ADR 的索引和摘要 |
| 测试索引.md | 测试用例和报告的索引 |
| Bug索引.md | Bug 的索引和摘要 |
| 决策记录.md | 重要决策记录 |

## 使用说明

当 AI 助手开始工作时，应首先阅读 LLM-WIKI.md，快速了解项目。
