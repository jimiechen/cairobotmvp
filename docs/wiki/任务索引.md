## 4. 维护规则

- 新增任务时使用 `/tabbit-task` Command 归档（Tabbit 来源）
- 新增 Trae 任务时使用 `/task-raw-archive` Command 归档（Trae 来源）
- 每条 Raw 记录必须有 **Source Record ID (SRC-ID)** 作为主键
- **Task ID (TB-ID) 为可选字段**：早期记录保留兼容，新记录不强制要求
- 蒸馏由 `tabbit-task-distillation` 或 `cairobot-llm-wiki-distillation` Skill 执行
- **Trae 执行的任务必须使用 `/task-raw-archive` 归档到 `docs/trae-export/inbox/tasks/YYYY/MM/`**
- **"Raw 记录"列追踪从 Raw → Distillation → Index 的全链路**
- **跨来源关联通过 [source-map.md](./source-map.md) 维护，不得仅凭 Task ID 强制对齐**
