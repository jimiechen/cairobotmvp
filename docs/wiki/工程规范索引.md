## 目录布局规范

详见 [ADR-0012](../adr/ADR-0012-polyglot-monorepo-directory-layout.md)

核心原则：
- 根目录只保留工程级公共资产
- Go 代码进 `go/`
- Python 代码进 `python/`
- TypeScript 代码进 `typescript/`
- Protobuf 保持在根目录 `proto/`
- 构建逻辑在 `scripts/` 下按用途分类

## 规范要点

### 1. 开发流程

- PRD 驱动
- Issue 驱动
- TDD 红-绿-重构
- 小步提交
- PR 评审
- 文档同步

### 2. 每日工作流

- 21:30 停止扩大开发范围
- 21:30-21:45 整理今日修改
- 21:45-22:00 生成日报
- 22:00 前提交日报
- 22:00 后 Markdown 蒸馏
- 更新 LLM Wiki

### 3. 编码规范

- 变量：lowerCamelCase
- 常量：UPPER_SNAKE_CASE
- 类：UpperCamelCase
- 文件：推荐 ≤300 行
- 方法：推荐 ≤30 行
- 默认中文注释

### 4. Git 规则

- 分支：feature/*, fix/*, docs/*, test/*, hardware/*
- 提交信息：type(scope): 中文说明
- PR 控制文件数量和代码行数

### 5. 报告机制

- 每日 22:00 前必须提交日报
- 事故立即上报
- 风险及时记录
- 测试需有报告和截图/视频证据
