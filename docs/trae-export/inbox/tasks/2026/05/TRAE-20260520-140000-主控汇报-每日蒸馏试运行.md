## 六、建议修改项（4 项建议改，非必须）

### 6.1 🟡 建议 1：SRC-ID HASH8 算法统一为真实 SHA-256 前 8 位

**现状**：本次 HASH8 使用占位值 `a1b2c3d4`，非真实内容哈希。

**风险**：正式任务若沿用占位，Raw 层"文件是否被篡改"的校验能力失效。

**建议**：
- 统一定义算法：`SHA256(file_full_path + "|" + timestamp_iso + "|" + first_1024_bytes).hex()[:8]`
- 编写脚本固化：`scripts/dev/generate-src-id.sh <file> <timestamp>` 输出标准 SRC-ID
- 在 cairobot-task-raw-archive Skill §4.1 中追加算法说明
- MVP 阶段若无法脚本化，至少在任务执行说明中显式写出"本次 HASH8 为真实哈希 vs 占位"

### 6.2 🟡 建议 2：Relation Group 编号与 source-map 候选联动

**现状**：本次分配 RG-20260520-001，但尚未登记到 `docs/wiki/source-map.md` 的 candidate 区（按禁止项未修改正式 Index 文件）。

### 6.3 🟡 建议 3：轻量任务的简化 2 产物模式
