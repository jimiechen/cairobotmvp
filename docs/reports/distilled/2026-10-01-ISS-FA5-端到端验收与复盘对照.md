## 3. 决策

- D10 复盘对照不上 MySQL 通道：无 SQL 契约不臆造，登记遗留待上游归档。
- 过热处置核验口径（BUG-FA5-01 修复）：处置标注在推荐单元 tag **或**
  `sentiment.overheat.tag`（含「过热」）+ `disposition` 分档给出，任一即合规——
  兼容 FA3「tag 先落 overheat 层、下沉推荐单元属后续补强」的实际链路。
- 验收 8 条中 make rules（308 项历史失败）与 MySQL 凭据未持久化两条不强行
  通过：如实标注部分通过/证据引用，引用 R-04 归档报告作既有证据。
