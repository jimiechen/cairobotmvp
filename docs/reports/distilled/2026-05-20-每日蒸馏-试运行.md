## 3. 今日完成决策

### 3.1 TarsGo 部署拓扑关键决策（经主控确认的架构口径修正）

📋 **规则 1**：**local ≠ 不使用 Tars**。local/单体模式 = TarsGo 单体部署模式，必须使用 TarsGo 框架（TarsHttpMux / AddHttpServant / Run），只是不连接远程 TarsCloud 注册中心（locator 为空）。

📋 **规则 2**：**LocalInvoker ≠ 绕过 Tars 的普通 Go 调用**。LocalInvoker = 单体部署模式下的本进程 TarsGo servant adapter，仍通过 Tars 框架层。

📋 **规则 3**：**TarsGoInvoker = 微服务部署模式的远程 client**。S0/S1 阶段允许仅定义接口而不实现真实远程调用。

📋 **规则 4**：**两种部署模式的唯一区别是部署拓扑**（同进程 vs 跨进程），技术基线（TarsGo）和 Tars bytes 契约完全一致。
