- Trae 任务 Raw 归档规范正式落地实施，目录确定为 `docs/trae-export/inbox/tasks/YYYY/MM/`
- Raw 归档是"任务完成汇报的结构化持久化版本"，与 reporting.md / project.md 不是重复流程
- 文件命名规范确定为 `{TASK_ID}.trae.raw.md`，与现有 `.trae.exec.md` 后缀区分
- 任务索引表保持 7 列格式不变，Trae Raw 路径填入"Raw 来源"列
- MVP 阶段只实现单 Command（`task-raw-archive`），暂不拆分为 start/close

### 架构类
- TarsGo HTTP 模块改造完成，proto-gateway 身份明确为"TarsGo HTTP Servant"
- Local 模式重新定义：是 TarsGo 单体部署模式，仍使用 TarsGo 框架运行，不绕过 Tars
- LocalInvoker = 本进程 TarsGo servant adapter，不是绕过 Tars 的普通 Go 调用
- TarsGoInvoker = 微服务部署模式下的远程 TarsGo client invoker，S1 阶段未实现
- 两种部署模式（单体 / 微服务）共享相同的 Tars bytes 契约，区别仅是部署拓扑
