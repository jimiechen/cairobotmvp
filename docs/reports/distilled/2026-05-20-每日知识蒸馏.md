### CR-1 每日汇报生成前的仓库状态确认标准流程（候选）

**适用场景**：每次日报 / Trae 任务执行前。

1. `pwd` → 确认当前在仓库根目录
2. `git remote -v` → 确认远程仓库 URL 无误
3. `git branch --show-current` → 确认当前分支（避免在错误分支产出）
4. `git rev-parse --abbrev-ref HEAD` → 二次确认 HEAD 分支
5. `git rev-parse --short HEAD` → 记录当前 commit hash（后续可追溯）
6. `git status --short` → 确认是否有未提交变更，写入 Raw 记录

（来源：本次用户任务要求 + 执行有效，高置信流程）
