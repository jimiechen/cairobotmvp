## 10. 需要 LLM 后续记住的上下文

### CTX1. 试运行模式的身份标记
- 当任务说明中出现"试运行"、"交由 Tabbit 主控确认"、"禁止 commit/push"、"不宣称最终完成，只能说明试运行产物已生成"等关键词时，应默认进入以下模式：
  - 所有产物路径/命名/关联的状态为 candidate / 待确认 / 试运行已生成。
  - 不修改 docs/wiki/ 下任何正式 Index 文件（每日蒸馏索引.md、source-map.md、任务索引.md、LLM-WIKI.md）。
  - Git 操作只允许只读（status、log、remote、branch、rev-parse 等），禁止任何写入操作。
  - 最终声明固定使用："试运行产物已生成，等待主控确认"。

### CTX2. 仓库状态前置检查 6 条标准命令清单（可复用）
- 当用户显式列出 6 条命令时，按给出顺序执行。
- 当后续类似任务未列出具体命令但要求"先确认仓库状态"时，默认清单为：
  1. `pwd`
  2. `git remote -v`
  3. `git branch --show-current`
  4. `git rev-parse --abbrev-ref HEAD`
  5. `git rev-parse --short HEAD`
  6. `git status --short`
- 可按需追加 `git log --oneline -20`，但不作为强制项。

### CTX3. Raw 归档路径（2026-05-20 评审后口径）
- Trae 任务 Raw 归档应放在：`docs/trae-export/inbox/tasks/YYYY/MM/`
- 禁止放在：`docs/wiki/raw/`
- 备选路径（如需与 reports 平级）：`docs/reports/raw-tasks/YYYY/MM/`

### CTX4. 严格禁止 10 条基线（可复用）
- 任何 docs 类试运行任务默认继承以下禁止项，除非用户显式豁免：
  1. 不允许 git commit
  2. 不允许 git push
  3. 不允许修改业务代码（go/、python/、web/、proto/、configs/、scripts/ 中非 docs 脚本、deploy/ 二进制等）
  4. 不允许重构目录（不新增/不删除/不移动目录）
  5. 不允许修复 Gateway/Tars 代码
  6. 不允许执行 destructive 命令（rm -rf、git reset --hard、git clean -fd、drop table、truncate 等）
  7. 不允许把失败命令写成通过
  8. 不允许把 pending / skip 写成 pass
  9. 不允许自动更新 main 分支（不 git pull origin main、不 merge、不 rebase）
  10. 不允许宣称"最终完成"，只能说明"试运行产物已生成，等待主控确认"

  1. 每日原始记录（Raw 归档）= 任务执行过程的完整事实记录（SRC-ID 作为主键）
