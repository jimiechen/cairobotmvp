### 2.1 TarsGo 部署拓扑定义澄清

**澄清内容**:
| 概念 | 旧定义（错误） | 新定义（正确） |
|---|---|---|
| local/单体模式 | 不使用 Tars | TarsGo 单体部署模式，使用 TarsGo 框架运行 |
| LocalInvoker | 本地调用实现 | 本进程 TarsGo servant adapter |
| TarsGoInvoker | TarsGo 调用实现（未实现） | 远程 TarsGo client invoker |
| proto-gateway 身份 | 单网关入口实现 | TarsGo HTTP Servant |

**关键约束**:
- local 模式仍使用 TarsGo 框架（TarsHttpMux/AddHttpServant/Run）
- 两种模式的共同点：都使用 TarsGo 框架 + Tars bytes 契约
- 区别仅是部署拓扑（驻同进程 vs 跨进程）
