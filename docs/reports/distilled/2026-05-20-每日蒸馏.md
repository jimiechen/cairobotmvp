## 2. 今日新增事实

- **事实 1**：TarsGo local 模式不是"不使用 Tars"，而是 TarsGo 单体部署模式，使用 TarsGo 框架运行（TarsHttpMux / AddHttpServant / Run），只是不连接远程 TarsCloud 注册中心
- **事实 2**：LocalInvoker 定义为"单体部署模式下的本进程 TarsGo servant adapter"，不绕过 Tars 框架
- **事实 3**：TarsGoInvoker 定义为"微服务部署模式下的远程 TarsGo client invoker"，S1 阶段未实现
- **事实 4**：proto-gateway 的身份是"TarsGo HTTP Servant"，不是单网关入口实现
- **事实 5**：Trae 任务 Raw 记录的推荐目录为 docs/trae-export/inbox/tasks/YYYY/MM/，不放在 docs/wiki/ 下
- **事实 6**：Raw 归档是任务完成汇报的结构化持久化版本，不是额外负担

## 3. 今日完成决策

- **决策 1**：TarsGo 两种部署模式共享相同 Tars bytes 契约，区别仅是部署拓扑（同进程 vs 跨进程）
- **决策 2**：Raw 归档使用 SRC-ID 作为主键，Task ID 可选，不强求与 Tabbit 对齐
- **决策 3**：MVP 阶段 Raw 归档使用单一 Command（task-raw-archive），不拆分为 start/close
- **决策 4**：任务索引表保持现有 7 列格式，新增 Trae 任务 Raw 记录填入"Raw 来源"列
