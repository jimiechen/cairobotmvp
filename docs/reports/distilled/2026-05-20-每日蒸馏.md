## 10. 需要 LLM 后续记住的上下文

### 10.1 TarsGo 架构澄清

- **单体部署模式 (local)**：使用 TarsGo 框架运行（TarsHttpMux/AddHttpServant/Run），只是不连接远程 TarsCloud 注册中心
- **LocalInvoker**：单体部署模式下的本进程 TarsGo servant adapter，不绕过 Tars 框架
- **TarsGoInvoker**：微服务部署模式下的远程 TarsGo client invoker

### 10.3 SOLO Web 职责边界

SOLO Web 推荐承担以下职责：
- 每日 Raw 采集
- 日报生成
- 蒸馏生成
- 主控汇报生成
- Index 更新候选生成

SOLO Web 不推荐承担：
- 业务代码修复
- 架构性重构
- 自动提交 main 分支
- 直接修改 LLM-WIKI.md
- Skill / Command 制作
- 长期知识库结构调整

### 10.4 Gateway 架构约束

- 业务入口必须是单网关入口
- 路由主键使用 `Type.max + Type.min`
- Tars 接口使用统一 bytes 签名
- AuditInvoker 应包裹 LocalInvoker 和 TarsGoInvoker
- 审计应记录：traceId、requestId、maxType、minType、target、method、returnCode、duration、request/response size+hash
- token、authorization、password 等敏感字段必须脱敏
