**核心修正点**：
1. local 模式是 TarsGo 单体部署模式，使用 TarsGo 框架运行，不是"不使用 Tars"
2. LocalInvoker = 本进程 TarsGo servant adapter，不绕过 Tars 框架

4. proto-gateway 身份：TarsGo HTTP Servant

**主要变更**：
- go.mod：新增 TarsCloud/TarsGo v1.4.6 依赖 + replace 指向本地 third_party

- 新增 gateway.local.conf：TarsGo 单体部署本地配置
- invoker.go：LocalInvoker / TarsGoInvoker 注释口径修正
- README.md：全面重写架构描述
