    扫描 modules/**/*.go 中的中文字符串字面量（排除注释、错误码 key）
    必须为空
L6. 必须存在 README.md：6 节 H2 标题（用 markdown lint 校验）
L7. 必须存在 *_seed.sql 或在 sample-module.md 中明确无 seed 需求

L9. modules/<name>/usecase_test.go 覆盖率 ≥80%（go test -cover）
