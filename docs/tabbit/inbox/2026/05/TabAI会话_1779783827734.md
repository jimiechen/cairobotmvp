### **以最小可用闭环为目标，先把 app_config 与 sys_lang_string 在 go-admin 上的「后端 CRUD + 前端操作页 + SDK 联动」三件套跑通，多租户、审核工单、联邦视图全部押后到 S2，整个交付周期压缩到 3~4 个工作日。**

下面这套方案严格遵循我们前几轮已经定下来的架构铁律：**写入必经 services/{config,i18n}/admin 子包、go-admin 仅做 UI + 控制器 + 鉴权、Redis pub/sub 广播失效、业务服务通过 SDK 100ms 内感知**。把多租户能力先关掉（默认单租户 default），但接口签名预留 tenant_id 字段，未来加租户不破坏现有数据。

  ✓ go-admin 自带 RBAC（先用 admin / operator / viewer 三角色够用）

### **四、API 设计**

#### **4.1 配置 Schema**

```text
GET    /api/admin/config/schema?module_key=&page=&size=
POST   /api/admin/config/schema
PUT    /api/admin/config/schema/:id
DELETE /api/admin/config/schema/:id
GET    /api/admin/config/schema/:id

请求体（POST/PUT）：
{
  "tenant_id": "default",
  "module_key": "hello_cfg",
  "field_key": "max_name_length",
  "field_type": "int",            // string/int/bool/float/enum/json/list
  "default_value": "32",
  "validator": "{\"min\":1,\"max\":256}",
  "is_required": true,
  "is_secret": false,
  "client_scope": "all",
  "min_app_ver": "",
  "description": "用户名最大长度"
}

校验规则（services/config/admin 层）：
- field_type 合法
- default_value 能按 field_type 解析
- validator JSON 合法且自洽
- module_key + field_key 唯一（同 tenant 下）
- 删除前必须先把 sys_config_version 中对应字段清空
```

#### **4.2 配置 Value**

```text
GET    /api/admin/config/value?env=prod&module_key=
POST   /api/admin/config/value         批量保存某 module 的所有字段
GET    /api/admin/config/value/:env/:module_key

请求体：
{
  "tenant_id": "default",
  "env": "prod",
  "module_key": "hello_cfg",
  "fields": {
    "max_name_length": "32",
    "server_name": "CaiRobot"
  },
  "publish": true
}

行为：
- services/config/admin.ValueService.Save()
- 校验每个字段必须存在 schema、值符合 type/validator
- 写 sys_config_version (version 自增整数)
- 失效 Redis: config:value:{tenant}:{env}:{module_key}:*
- 发布 pub/sub: cairobot.config.invalidate
```

#### **4.3 i18n String**

```text
GET    /api/admin/i18n/string?lang_code=&group=&key_like=&page=&size=
POST   /api/admin/i18n/string                    新增（含全部语言一次性提交）
PUT    /api/admin/i18n/string/:key                修改
DELETE /api/admin/i18n/string/:key                软删除（operation_type=DEL）
GET    /api/admin/i18n/string/:key                详情

请求体（多语言并排）：
{
  "tenant_id": "default",
  "key": "svc_hello_greeting",
  "group": "app",
  "template_type": "named",         // plain/named/icu
  "params_schema": [
    {"name":"name","type":"string","required":true},
    {"name":"server_name","type":"string","required":true}
  ],
  "preview_sample": {"name":"张三","server_name":"CaiRobot"},
  "values": {
    "zh-CN": "你好，{name}！欢迎使用 {server_name}。",
    "en":    "Hello, {name}! Welcome to {server_name}."
  }
}

强校验（template_validator）：
- value 中所有 {xxx} 占位符必须出现在 params_schema
- params_schema 中 required=true 的参数必须出现在所有语言 value 中
- 不同语言 value 占位符集合必须一致
- preview_sample 必须能 plain/named/icu 渲染成功
- ICU 模板用现成库做语法校验
```

#### **4.4 i18n Pack**

```text
GET  /api/admin/i18n/pack
POST /api/admin/i18n/pack/publish     按 tenant + lang_code 自增 version + 失效广播

请求体：
{
  "tenant_id": "default",
  "env": "prod",
  "lang_code": "zh-CN",
  "description": "新增 svc_demo_msg"
}

行为：
- sys_lang_pack.version 自增 1
- 失效 Redis: i18n:pack:{tenant}:{env}:{lang_code}:* 与 i18n:diff:{tenant}:{env}:{lang_code}:*
- 发布 cairobot.i18n.invalidate
```

#### **4.5 i18n CSV 导入导出**

```text
POST /api/admin/i18n/string/import     multipart/form-data，CSV
GET  /api/admin/i18n/string/export?lang_code=

CSV 列：key,group,template_type,params_schema_json,zh-CN,en

行为：
- 导入逐行调用 services/i18n/admin.StringService.Save()
- 任何一行校验失败整体回滚
- 返回每行结果（成功/失败原因）
- 100 条 ≤2 秒
```

### **五、前端页面（admin-web）设计**

按 go-admin-ui Vue3 + Element Plus 风格实现，不改主题。

#### **5.1 Schema 列表页（schema-list.vue）**

```text
顶部筛选：
  [模块下拉] [字段类型下拉] [是否必填] [关键字搜索] [刷新] [新增]

表格列：
  module_key | field_key | type | default | required | secret | scope | desc | 操作

操作：
  编辑 | 删除（带二次确认）

特殊：
  按 module_key 分组折叠（可选）
```

#### **5.2 Schema 表单页（schema-form.vue）**

```text
字段：
  - tenant_id (隐藏，固定 default)
  - module_key (input)
  - field_key (input)
  - field_type (select：string/int/bool/float/enum/json/list)
  - default_value (按 type 动态：input/switch/number/textarea)
  - validator (textarea，type 切换时给出 JSON 模板)
  - is_required (switch)
  - is_secret (switch)
  - client_scope (select：all/android/ios/web/admin)
  - min_app_ver (input，可空)
  - description (textarea)

提交前前端先做一遍校验（与后端规则一致），后端再校验一遍。
```

#### **5.3 Value 列表页（value-list.vue）**

```text
顶部：
  [env 切换 dev/test/prod] [module_key 选择] [刷新]

表格：
  field_key | 当前值 | 类型 | 默认值 | 是否覆盖默认 | 描述

底部：
  [批量保存] [发布]
  保存按钮置灰直到表单 dirty
```

#### **5.4 Value 表单页（value-form.vue）**

```text
按 schema 动态渲染：
  - string  → input
  - int/float → number
  - bool   → switch
  - enum   → select（从 validator.enum 取选项）
  - json   → JSON 编辑器（含格式化按钮）
  - list   → 标签输入

校验：
  按 schema.validator 实时校验，前端 + 后端各一遍

预览区：
  右侧固定预览面板，展示当前 module 完整 JSON
```

#### **5.5 i18n String 列表页（string-list.vue）**

```text
顶部筛选：
  [group 下拉] [template_type 下拉] [key 模糊搜索] [刷新] [新增] [导入] [导出]

表格（重点：多语言并排）：
  key | group | type | zh-CN | en | params 数量 | 操作

操作：
  编辑 | 删除 | 复制（基于现有 key 创建新 key）

行内编辑：
  zh-CN / en 列双击进入快速编辑模式（仅 plain 类型可行内改）
  named / icu 必须进入完整表单
```

#### **5.6 i18n String 表单页（string-form.vue）**

```text
左半区：
  - key (input)
  - group (select：common/app/error/topic/user/...)
  - template_type (radio：plain/named/icu)
  - params_schema (动态表格：name/type/required/default，type 为 named/icu 时显示)
  - preview_sample (JSON 编辑器)

右半区：
  - 多语言 Tab 或并排：
    - zh-CN：textarea
    - en：textarea
  - 实时占位符高亮（{xxx}）
  - 实时校验：
    - 占位符未在 params_schema → 红色波浪线
    - params_schema required 缺失 → 红色提示
    - 跨语言占位符不一致 → 黄色警告
  - 实时预览：
    - 用 preview_sample + 当前 value 渲染
    - 渲染失败显示具体错误

底部：
  [取消] [保存草稿（可选）] [保存并发布]
  保存并发布 = Save + Pack.publish 一起调用
```

#### **5.7 Pack 管理页（pack-list.vue）**

```text
表格：
  env | lang_code | 当前 version | 最近发布时间 | 描述 | 操作

操作：
  发布新版本（弹窗输入描述）
  查看历史
```

#### **5.8 导入导出页（import-export.vue）**

```text
导入：
  - 文件上传（CSV）
  - 上传后预览前 10 行
  - 显示每行校验状态
  - 全部通过后才出现"确认导入"按钮
  - 导入完成显示成功/失败统计

导出：
  - 选择 lang_code（可多选）
  - 选择 group（可多选）
  - 下载 CSV
```
