**关键验证点：**
- [x] MessagePacket Protobuf 编解码正确性
- [x] 路由配置加载和验证
- [x] maxType:minType 路由匹配
- [x] HTTP Server 错误处理（405/415/400）

- [x] TarsGoInvoker 未实现明确报错（返回 10500，S1 阶段远程调用未实现）
- [x] E2E HealthCheck 全链路（HTTP → Gateway → LocalInvoker → SystemService → 响应）
- [x] MessagePacket.data 使用 Protobuf binary bytes（非 JSON）

**技术决策记录：**
- **MessagePacket.data 格式：** 固定使用 Protobuf binary bytes
- **决策原因：**
  1. Protobuf 是 CaiRobot MVP 当前唯一协议契约
  2. 协议编号 maxType + minType 绑定 Protobuf message
  3. Tars bytes 接口天然承载 Protobuf bytes
  4. 当前实现已向 Protobuf bytes 收口
  5. 避免引入第二套协议语义
- **决策日期：** 2026-05-20
- **决策人：** 项目主控
