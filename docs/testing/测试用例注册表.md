## 注册规则

1. **必须登记**：所有 `*_test.go`、`test_*.py`、`*.test.ts` / `*.spec.ts` 文件必须在注册表中登记
2. **必须存在**：注册表中登记的测试文件必须实际存在于代码库中
3. **协议关联**：协议编号新增时必须有对应测试用例
4. **废弃标注**：废弃测试必须标注原因和废弃日期
