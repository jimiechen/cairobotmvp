**技术决策记录：**
- **MessagePacket.data 格式：** 固定使用 Protobuf binary bytes
- **决策日期：** 2026-05-20
- **决策人：** 项目主控
- **ADR 文档：** ADR-0014

**架构约束（来自 ADR-0014）：**
1. Gateway 不做 JSON 编解码，只透传 Protobuf bytes
2. 业务模块接收 `[]byte` (Protobuf)，内部自行 Unmarshal/Marshal
3. 测试构造使用 `proto.Marshal()` / `proto.Unmarshal()`
4. 不引入第二套协议语义

**模块化架构要点（Phase 3 确认）：**
1. **Adapter 模式**：`ModuleInvokeFunc` → `moduleHandler` → `LocalHandler` 接口适配
2. **独立注册**：每个模块通过 `RegisterModuleHandlers()` 独立注册到 TargetKey
3. **返回码标准化**：模块成功统一返回 10200，失败统一返回 10500
4. **向后兼容**：`RegisterSystemHandlers()` 保留，旧代码无需修改
5. **包可见性**：模块包从 `internal/modules/` 提升到 `modules/`，允许 Gateway 层导入
