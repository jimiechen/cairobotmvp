# 截图/视频证据规范

## 1. 证据要求

### 1.1 必须保留证据的场景

以下情况必须保留截图或视频证据：

- 端到端测试
- UI 测试
- 硬件相关测试
- 安全边界测试
- Bug 复现与验证
- 验收测试

### 1.2 证据目的

- 证明测试实际执行了
- 证明结果符合预期
- 便于后续问题复现
- 便于评审验证

## 2. 证据存放

| 类型 | 目录 |
|---|---|
| 截图 | `docs/reports/screenshots/` |
| 视频 | `docs/reports/videos/` |

## 3. 文件命名规范

### 3.1 截图命名

格式：

```text
YYYY-MM-DD_TC-XXX_[场景名]_[序号].png
```

示例：

```text
2026-05-17_TC-001_设备绑定成功.png
2026-05-17_TC-002_设备绑定成功_step1.png
2026-05-17_TC-002_设备绑定成功_step2.png
```

### 3.2 视频命名

格式：

```text
YYYY-MM-DD_TC-XXX_[场景名].mp4
```

示例：

```text
2026-05-17_TC-001_设备绑定成功.mp4
2026-05-17_TC-003_AI过滤违规词.mp4
```

## 4. 截图要求

- 清晰可读
- 显示完整
- 包含关键 UI/UI 或数据
- 不包含敏感信息
- 尺寸适中

## 5. 视频要求

- 帧率适中
- 关键操作清晰
- 时长不宜过长
- 不包含敏感信息
- 关键步骤可用快进

## 6. 证据引用

测试报告中必须引用证据文件路径：

```markdown
### 8. 截图证据

| 截图 | 对应步骤 | 说明 |
|---|---|---|
| ../screenshots/2026-05-17_TC-001_step1.png | 1 | 设备扫描二维码 |
| ../screenshots/2026-05-17_TC-001_step2.png | 2 | 绑定成功界面 |
```

## 7. 证据与测试断言的关系

**证据不能替代测试断言：

- 测试断言：代码判断通过/失败
- 证据：辅助验证断言的视觉证据

两者都必须同时存在。
