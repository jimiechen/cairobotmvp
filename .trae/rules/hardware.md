# 硬件开发规则

MVP 硬件使用 ESP32-S3 作为底座控制器。

## 硬件模块

MVP 硬件包含：

- 12V 输入。
- 5V 电源轨。
- 3.3V 电源轨。
- 舵机锁或电子锁。
- 舱门开关。
- 手机存在检测。
- 锁状态检测。
- LED 补光灯。
- 风扇。
- 温度传感器。
- 状态灯。
- 蜂鸣器。
- 扩展接口。

## 设计原则

- MVP 使用外接适配器供电。
- MVP 不做电池系统。
- 舵机、补光灯电源应与 MCU 逻辑电源合理隔离。
- 执行器不得直接由 GPIO 供电。
- 开关输入必须有上拉或下拉。
- MOS 管栅极必须有下拉。
- 舵机和补光灯附近必须放置大容量电容。
- 所有接口必须有清晰丝印。
- 优先预留调试接口。

## MVP 不包含

- 内置投影仪。
- 电池充电管理。
- 复杂多轴机械臂。
- 大功率电机驱动。
- 高频复杂音频阵列。
