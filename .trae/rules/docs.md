# 文档规则

本项目必须文档先行。

## PRD

PRD 放在：

`docs/prd/`

PRD 必须包含：

- 背景。
- 目标。
- 非目标。
- 用户角色。
- 用户流程。
- 功能需求。
- 安全需求。
- 验收标准。

## ADR

架构决策放在：

`docs/adr/`

ADR 必须包含：

- 状态。
- 背景。
- 决策。
- 后果。

## API

设备和 App 通信协议放在：

`docs/api/`

## 测试

测试策略放在：

`docs/testing/`

## 约束

不得实现 PRD 或 ADR 未描述的核心行为。
任何行为变更必须更新相关文档。
