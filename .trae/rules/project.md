# Trae 项目规则

你正在开发 CaiRobot MVP。

在写任何代码之前，必须先阅读：

1. `AGENTS.md`
2. `docs/prd/` 下相关 PRD
3. `docs/adr/` 下相关 ADR
4. 当前 Issue 或任务描述

如果没有明确 Issue，不要实现功能，应先要求创建 Issue。

## 禁止行为

不得：

- 生成大段未请求代码。
- 修改无关文件。
- 擅自增加新产品功能。
- 擅自修改 PRD。
- 将孩子原始输入直接发送给大模型。
- 实现无限制开放聊天。
- 实现儿童监控、人脸追踪或行为监控。
- 绕过家长控制。
- 在异常情况下自动解锁手机仓。

## 必须行为

必须：

- 使用中文输出说明、评审和文档。
- 使用 TDD 流程。
- 先写测试，再写实现。
- 保持变更小而清晰。
- 行为变化时同步更新文档。
- 完成后说明修改了哪些文件、运行了哪些测试。
