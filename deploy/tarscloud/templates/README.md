# TarsCloud 模板

## 概述

本目录包含 TarsCloud 服务部署的模板文件，用于快速创建和部署新的 TarsGo 服务。

## 模板列表

| 模板 | 说明 |
|------|------|
| service.tpl | 服务配置模板 |
| servant.tpl | Servant 接口定义模板 |
| config.conf.tpl | 服务配置文件模板 |
| build.sh.tpl | 构建脚本模板 |

## 使用说明

使用模板创建新服务时，请参考各模板文件中的注释信息进行配置。
