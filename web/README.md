# Web

CaiRobot MVP 前端项目集合。

## 项目列表

| 项目名称 | 目录 | 说明 |
|---------|------|------|
| 服务商后台前端 | provider-admin/ | 服务商管理后台 |
| 用户中台前端 | user-center/ | 家庭用户管理后台 |
| 终端 App/H5 | app/ | 终端用户 App 或 H5 |

## 技术栈

- 框架：ReactJS
- UI 组件库：待定（Ant Design / Material-UI）
- 状态管理：待定（Redux / MobX / Context）
- 路由：React Router
- 测试：Jest + React Testing Library
