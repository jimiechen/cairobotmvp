# IA-09 缺 Pack ID 查询结果为空

## 测试用例编号

IA-09（字符串列表 - 缺少 Pack ID 时查询为空）

## 截图时间

2026-05-28 08:32:26

## 页面描述

当用户未选择或未传入有效的 Pack ID（语言包标识）时，字符串列表查询返回空结果的页面状态。列表区域展示"暂无数据"的空状态提示，而非报错或加载失败。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 查询条件区域 | 包含 Pack ID 选择器等筛选条件 | 正常显示 |
| Pack ID 字段 | 当前为空或未选择有效值 | 未填/无效 |
| 数据表格区域 | 列表主内容区 | 显示空状态 |
| 空状态提示 | "暂无数据"文案及可能的空状态插图 | 正常显示 |
| 表头 | 表格列头（ID、String Key 等）可能仍显示或隐藏 | 视设计而定 |

## 预期行为

1. **触发条件**：
   - 用户进入页面但未选择 Pack ID
   - 或用户清除了已选择的 Pack ID
   - 或传入的 Pack ID 无效/不存在
2. **请求行为**：
   - 不发送无意义的空查询请求（前端拦截）
   - 或发送请求后后端返回空数据集
3. **UI 展示**：
   - 不显示加载中状态
   - 不显示错误提示
   - 表格区域显示友好的空状态占位（"暂无数据"）
4. **引导操作**：提示用户先选择有效的 Pack ID 以加载数据

## 关联测试场景

- 对比验证：与 [ia-08-字符串列表正常渲染](./ia-08-字符串列表正常渲染.md) 形成对比——有 Pack ID 时有数据，无 Pack ID 时为空
- 边界场景：验证系统对缺失必选参数的优雅处理能力
