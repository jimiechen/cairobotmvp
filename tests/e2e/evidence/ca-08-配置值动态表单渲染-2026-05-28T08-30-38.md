## 页面描述

截图展示的是 **配置值发布页面** 的初始渲染状态。用户已选择模块 Key 为 `app.server`，环境为 `开发 (dev)`，系统根据该模块的 Schema 定义动态生成了 3 个配置字段的输入表单。每个字段的控件类型根据 Schema 中的字段类型（int / bool）自动匹配对应的 UI 组件。

## 预期行为

1. **模块选择联动**：当用户在下拉框中选择一个模块 Key 时，前端通过 API 查询该模块关联的 Schema 定义
2. **动态表单生成**：根据返回的 Schema 字段列表，按顺序渲染每个字段的输入控件
3. **类型智能匹配**：
   - `int` 类型 → 数字输入框，支持上下步进调整
   - `bool` 类型 → Switch 开关，显示"开/关"状态
   - `string` 类型 → 普通文本输入框
4. **默认值回填**：每个字段自动填充 Schema 中定义的默认值
5. **必填标识**：所有动态生成的字段均带有必填标记（⚠ 图标）
6. **字段计数显示**：区域标题实时显示当前渲染的字段数量 `(3 个)`
7. **未选模块时**：不显示动态字段区域，仅显示基础选择表单

## 技术实现要点

- 动态表单基于 Schema 驱动，非硬编码
- 字段类型标签使用不同颜色区分，提升可读性
- 数字输入框内置 min/max 校验（由 Schema 定义决定）
- Switch 开关的双向绑定值为 boolean 类型
