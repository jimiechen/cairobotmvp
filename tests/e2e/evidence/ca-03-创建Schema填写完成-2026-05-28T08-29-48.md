## 预期行为

1. **表单验证规则**：
   - 模块 Key、字段 Key、字段类型为必填项，提交前需校验非空
   - 当字段类型为 int 时，默认值应接受数字输入
   - 校验规则 JSON 应支持 JSON 格式校验（可选）

2. **字段联动逻辑**：
   - 字段类型选择不同值时，默认值的输入控件应相应变化（int→数字框，string→文本框）
   - 是否必填开关影响 Schema 的校验行为

3. **用户体验要求**：
   - 所有输入框应有清晰的占位符提示
   - 必填项应有明显的视觉标识（红色星号）
   - 表单填写过程中不应出现意外报错或数据丢失
