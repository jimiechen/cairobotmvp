# IA-13 空版本号回滚警告提示

## 测试用例编号

IA-13（回滚语言包 - 版本号为空的初始状态）

## 截图时间

2026-05-28 08:33:01

## 页面描述

回滚语言包操作页面的初始状态或重置状态。"回滚到版本"字段值为 0（空值/默认值），表示用户尚未选择要回滚到的目标版本。此截图记录了回滚操作的起始状态。

## 关键元素

| 元素 | 描述 | 状态/值 |
|------|------|---------|
| 页面标题 | "回滚语言包"或类似标题 | 正常显示 |
| 语言包ID/选择器 | 指定要回滚的语言包 | 已选有效值 |
| 回滚到版本输入框 | 目标版本号字段 | **值为 0（空/默认）** |
| 回滚按钮 | 触发回滚操作的按钮 | 可能处于禁用或启用状态 |

## 预期行为

1. **页面初始态**：
   - 用户进入回滚页面
   - 版本号字段显示默认值 0 或为空
2. **校验逻辑**：
   - 版本号为 0 或空时，回滚按钮应禁用或点击后给出错误提示
   - 版本号必须为有效的正整数且不超过当前版本号
3. **用户操作流程**：
   - 用户先选择/输入有效的目标版本号
   - 校验通过后回滚按钮变为可用状态
   - 点击回滚执行操作
4. **后续状态**：成功回滚后参见 [ia-12-回滚语言包成功后状态](./ia-12-回滚语言包成功后状态.md)

## 关联测试场景

- 后续验证：[ia-12-回滚语言包成功后状态](./ia-12-回滚语言包成功后状态.md) 展示填写有效版本号并执行回滚后的成功状态
- 边界场景：验证系统对无效版本号（0、负数、超出范围）的处理能力
