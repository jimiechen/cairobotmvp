# IA-11 空 Body 发布语言包校验提示

## 测试用例编号

IA-11（发布语言包 - 语言包 ID 为空的校验提示）

## 截图时间

2026-05-28 08:32:46

## 页面描述

发布语言包操作页面中，用户尝试提交发布请求但未填写必填字段"语言包 ID"时，系统触发表单前端校验，在对应字段下方显示红色错误提示信息"请输入语言包 ID"。这是对空请求体（Empty Body）场景的前端防护。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 页面标题 | "发布语言包" | 正常显示 |
| 语言包ID输入框 | **必填字段**，指定要发布的语言包标识 | **为空** |
| 语言包ID错误提示 | 红色文字"请输入语言包ID" | **已显示** |
| 目标环境选择器 | 选择发布目标环境 | 可能已选或未选 |
| 语言码输入框/选择器 | 目标语言代码 | 可能已填或未填 |
| 发布按钮 | 已点击触发校验 | 触发源 |

## 预期行为

1. **触发条件**：用户点击"发布"按钮时，语言包 ID 字段值为空
2. **前端校验拦截**：
   - 不发送 HTTP 请求到后端（防止空 Body 请求）
   - 在语言包 ID 字段下方显示红色错误文案
3. **错误信息**：
   - 文案："请输入语言包ID"
   - 样式：红色字体，位于字段正下方
4. **防御深度**：
   - 前端：表单级校验拦截
   - 后端：即使绕过前端也应拒绝空 body 请求并返回 400 错误
5. **恢复方式**：填写有效语言包 ID 后错误消失，按钮可正常提交
