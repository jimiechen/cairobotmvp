## 页面描述

CSV 导出功能页面的正常可操作状态。用户已填写"源 Pack ID"字段（值为 1），"导出 CSV"按钮处于可用状态，点击后可触发后端生成并下载指定语言包的字符串数据为 CSV 文件。

## 关键元素

| 元素 | 描述 | 状态/值 |
|------|------|---------|
| 页面标题 | "CSV 导出"或类似标题 | 正常显示 |
| 源 Pack ID 输入框 | **必填字段**，指定要导出的源语言包标识 | **已填：1** |
| 导出 CSV 按钮 | 触发导出下载操作的按钮 | **可用状态（可点击）** |

## 预期行为

1. **前置条件**：用户已填写有效的源 Pack ID（截图显示值为 `1`）
2. **按钮状态**：
   - Pack ID 有效时："导出 CSV"按钮启用、可点击
   - Pack ID 为空时：按钮禁用或点击触发校验错误
3. **执行导出**：
   - 点击"导出 CSV"按钮
   - 前端发送 GET/POST 请求到导出 API，携带 Pack ID 参数
   - 后端查询该语言包下所有字符串记录
   - 后端生成 CSV 文件流并以 `Content-Disposition: attachment` 方式返回
4. **浏览器下载行为**：
   - 浏览器自动触发文件下载
   - 文件名通常包含语言包标识和时间戳（如 `pack_1_strings_20260528.csv`）
5. **导出内容**：CSV 文件应包含 String Key、字符串值、分组、版本等完整字段
