# IA-17 无效 Pack ID 导入错误提示

## 测试用例编号

IA-17（CSV 导入导出 - 目标 Pack ID 为空的校验错误）

## 截图时间

2026-05-28 08:33:31

## 页面描述

CSV 导入操作中，用户已选择文件但未填写"目标 Pack ID"字段时，系统触发表单校验，在 Pack ID 字段下方显示红色错误提示信息"请输入目标 Pack ID"，阻止无效请求的提交。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 文件上传区域 | 已上传 CSV 文件 | **已选文件** |
| 目标 Pack ID 输入框 | **必填字段**，指定导入目标语言包 | **为空** |
| Pack ID 错误提示 | 红色文字校验错误信息 | **"请输入目标PackID"** |
| 开始导入按钮 | 触发导入操作的按钮 | 已点击触发校验 |

## 预期行为

1. **触发条件**：
   - 用户已选择有效的 CSV 文件
   - 目标 Pack ID 字段为空或未填写
   - 用户点击"开始导入"按钮
2. **前端校验拦截**：
   - 不发送 HTTP 请求到后端
   - 在目标 Pack ID 字段下方显示红色错误文案
3. **错误信息**：
   - 文案："请输入目标PackID"
   - 样式：红色字体，位于字段正下方
4. **多字段联动**：
   - 文件已选 + Pack ID 为空 → 仅提示 Pack ID 错误
   - 文件未选 + Pack ID 为空 → 双重提示或优先提示文件缺失
5. **恢复方式**：填写有效 Pack ID 后错误消失，可正常执行导入
