## 页面描述

截图展示的是 **配置值发布页面** 在提交配置值后触发了服务端校验失败的错误状态。页面顶部出现了红色的全局错误提示条（仅显示红色叉号图标），而表单区域的数据保持不变。这对应于服务端返回 HTTP 10400（参数校验失败）的场景。

## 关键元素

### 1. 错误提示条（页面顶部）— 核心验证点
- **位置**：页面顶部导航栏下方
- **背景色**：浅红色 / 粉红色背景
- **图标**：红色圆形 ❌ 叉号图标
- **文案**：仅显示图标，无详细错误文字（或文字被截断）
- **含义**：表示本次发布请求被服务端拒绝，原因为参数校验未通过

## 预期行为

1. **校验触发**：用户点击"发布配置"按钮，前端将表单数据提交至后端
2. **服务端校验失败**：后端对配置值进行业务规则校验（如 port 超出合法范围、timeout 为负数等），返回 HTTP 10400 错误码
3. **错误提示渲染**：前端接收到 10400 响应后，在页面顶部渲染红色错误提示条
4. **表单数据保留**：用户已填写的配置值不被清空，方便用户查看和修正问题字段
5. **不阻断交互**：错误提示出现后，用户仍可以修改表单并重新提交
6. **错误可关闭**：提示条应支持手动关闭（点击 × 或自动消失）

## 10400 错误码说明

| 字段 | 说明 |
|---|---|
| HTTP 状态码 | 10400（自定义业务错误码，表示 Parameter Validation Failed） |
| 触发场景 | 配置值不符合 Schema 定义的约束条件（如范围越界、类型不匹配、正则不通过等） |
| 典型原因 | port 值超出允许端口范围（1-65535 但可能被业务限制为更小范围）、timeout 为负数等 |
