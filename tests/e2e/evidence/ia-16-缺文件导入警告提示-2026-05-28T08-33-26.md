# IA-16 缺文件导入警告提示

## 测试用例编号

IA-16（CSV 导入导出 - 未选择文件时导入按钮禁用）

## 截图时间

2026-05-28 08:33:26

## 页面描述

CSV 导入页面中，用户尚未选择任何 CSV 文件时的状态。"开始导入"按钮处于禁用（disabled）状态，防止用户在未选择文件的情况下触发无效的导入请求。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 文件上传区域 | 拖拽或点击上传区域 | **无已选文件** |
| 目标 Pack ID 输入框 | 导入目标语言包标识 | 可能已填或未填 |
| 开始导入按钮 | 触发导入操作的提交按钮 | **禁用状态（disabled）** |
| 按钮样式 | disabled 状态下的视觉表现 | 灰色/半透明/不可点击 |

## 预期行为

1. **前置条件**：用户进入 CSV 导入页面，尚未选择文件
2. **按钮状态管理**：
   - 未选择文件时："开始导入"按钮为 `disabled` 属性
   - 按钮视觉呈现灰色或降低透明度
   - 鼠标悬停不显示可点击指针（cursor: not-allowed）
3. **交互保护**：
   - 点击禁用按钮不产生任何效果
   - 不发送 HTTP 请求到后端
4. **状态恢复**：
   - 用户选择有效 .csv 文件后 → 按钮变为可用
   - 用户同时填写有效的 Pack ID → 按钮完全可用
5. **用户体验**：可通过 tooltip 或提示文案告知用户为何按钮不可用
