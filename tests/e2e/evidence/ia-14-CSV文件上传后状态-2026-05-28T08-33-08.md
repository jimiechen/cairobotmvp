# IA-14 CSV 文件上传后状态

## 测试用例编号

IA-14（CSV 导入导出 - 文件上传区域初始状态）

## 截图时间

2026-05-28 08:33:08

## 页面描述

CSV 导入导出功能页面中，文件上传区域的初始/等待状态。页面显示拖拽上传提示文案，引导用户通过拖拽或点击方式选择 CSV 文件进行导入操作。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 文件上传区域 | 虚线边框的拖拽上传容器 | 正常显示 |
| 拖拽提示图标 | 上传/云朵图标 | 正常渲染 |
| 拖拽提示文案 | "将文件拖到此处，或点击上传"或类似引导文字 | 正常显示 |
| 文件格式提示 | 支持的文件格式说明（.csv） | 正常显示 |
| 目标 Pack ID 输入框 | 指定导入目标语言包 | 待填写 |
| 开始导入按钮 | 触发导入操作的按钮 | **禁用状态**（未选择文件时） |

## 预期行为

1. **初始展示**：
   - 进入 CSV 导入页面时，上传区域处于等待状态
   - 显示友好的拖拽/点击上传引导
2. **交互方式**：
   - 拖拽：用户将 CSV 文件拖入虚线区域后自动捕获
   - 点击：点击上传区域触发系统文件选择器
3. **文件校验**：
   - 选择文件后校验文件格式（必须为 .csv）
   - 非格式文件应给出错误提示并拒绝
4. **按钮联动**：
   - 未选文件时："开始导入"按钮为 disabled 状态
   - 选好文件且填好 Pack ID 后：按钮变为可用状态
