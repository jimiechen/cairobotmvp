## 页面描述

语言包字符串管理页面的正常数据展示状态。页面以表格形式展示当前语言包下的所有字符串记录，包含完整的字段信息和操作入口。

| 元素 | 描述 | 状态 |
|------|------|------|
| 页面标题 | "字符串管理"或类似标题 | 正常显示 |
| 查询条件区域 | Pack ID 选择器、搜索框等筛选条件 | 正常显示 |
| 数据表格 | 核心内容区，以行列形式展示字符串数据 | 正常渲染 |
| ID 列 | 每条字符串记录的唯一标识符 | 正常显示 |
| String Key 列 | 字符串的键名（如 `app.title`、`btn.submit`） | 正常显示 |
| 字符串值列 | 字符串对应的实际文本值 | 正常显示 |
| 分组列 | 字符串所属的分组/命名空间 | 正常显示 |
| 模板类型列 | 字符串的模板类型（纯文本/含变量等） | 正常显示 |

| 操作列 | 编辑、删除等操作按钮 | 正常显示 |
| 分页组件 | 底部分页导航（如有） | 正常显示 |

## 预期行为

1. **数据加载**：进入页面后自动请求字符串列表接口
2. **表格渲染**：
   - 表头正确显示所有列名
   - 数据行正确填充各字段值
   - 截图中共展示 3 条记录
3. **交互功能**：
   - 操作列按钮可点击
   - 支持按条件筛选/搜索
4. **样式一致性**：表格对齐方式、字体大小、间距符合设计规范
