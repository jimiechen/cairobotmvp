# IA-07 删除字符串成功后列表刷新

## 测试用例编号

IA-07（删除字符串 - 成功后列表刷新）

## 截图时间

2026-05-28 08:32:14

## 页面描述

执行删除字符串操作并确认后，系统返回到语言包字符串列表页面。页面顶部显示操作成功的反馈提示，列表数据已自动刷新，被删除的记录已从列表中移除。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 成功提示条 | 页面顶部绿色提示横幅，显示"删除成功" | 正常显示 |
| 字符串列表表格 | 主内容区域的数据列表 | 已刷新 |
| 列表表头 | 包含 ID、String Key、字符串值、分组、模板类型、版本、操作等列 | 正常渲染 |
| 操作列 | 每行右侧的编辑/删除等操作按钮 | 正常显示 |

## 预期行为

1. **确认删除后**：对话框关闭，发送 DELETE 请求到后端 API
2. **请求成功**：后端返回 200/204 状态码
3. **UI 反馈**：
   - 顶部出现绿色 Toast 提示"删除成功"，持续数秒后自动消失
   - 字符串列表自动重新请求最新数据（不依赖手动刷新）
4. **数据一致性**：
   - 被删除的字符串记录不再出现在列表中
   - 剩余记录的序号/分页信息正确更新
5. **幂等性**：重复删除同一记录应返回合理错误或无副作用

- 验证要点：确认删除操作完整流程的终态——列表已更新且提示正确
