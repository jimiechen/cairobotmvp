# IA-10 发布语言包 - 校验错误（语言码缺失）

## 测试用例编号

IA-10（发布语言包 - 表单校验错误）

## 截图时间

2026-05-28 08:32:37

## 页面描述

发布语言包操作页面中，用户点击"发布"按钮但未填写必填字段"语言码"时，系统触发表单前端校验，在对应字段下方显示红色错误提示信息。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 页面标题 | "发布语言包"或类似标题 | 正常显示 |
| 语言包ID输入框 | 用于指定要发布的语言包标识 | 已填写或未填 |
| 目标环境选择器 | 选择发布目标环境（dev/staging/prod） | 可选 |
| 语言码输入框/选择器 | **必填字段**，用于指定目标语言代码 | **为空** |
| 语言码错误提示 | 红色文字"请输入或选择语言码" | **已显示** |
| 发布按钮 | 触发发布操作的提交按钮 | 已点击触发校验 |

## 预期行为

1. **触发条件**：用户点击"发布"按钮时，语言码字段值为空
2. **前端校验拦截**：
   - 不发送 HTTP 请求到后端
   - 在语言码字段下方显示红色错误文案
   - 页面滚动/聚焦到首个错误字段
3. **错误提示样式**：
   - 文字颜色：红色（#F5222D 或类似）
   - 位置：字段正下方
   - 内容："请输入或选择语言码"
4. **恢复方式**：用户填写有效的语言码后，错误提示自动消失
5. **多错误场景**：若同时存在多个必填字段为空，应全部展示错误
