## 页面描述

截图展示的是 **配置 Schema 管理页面** 在执行删除操作后的状态。页面顶部显示绿色成功提示条，列表区域已刷新并展示当前最新的 Schema 数据。

## 关键元素

### 1. 成功提示条（页面顶部）
- **位置**：页面顶部导航栏下方
- **样式**：浅绿色背景 + 绿色勾选图标
- **文案**：`删除成功`
- **行为**：提示条在操作成功后自动出现，一段时间后可关闭

### 2. 面包屑导航
- 路径：`首页 > Schema 管理`
- 当前激活标签页为 **Schema 管理**

### 3. 查询条件区
- **模块 Key** 输入框：占位符文本 `请输入模块标识`
- **搜索** 按钮：蓝色主按钮
- **重置** 按钮：灰色次按钮

### 4. 操作按钮区
- **+ 新增 Schema** 按钮：蓝色主按钮
- **批量删除** 按钮：红色/危险色按钮

### 5. Schema 数据表格

| 列名 | 说明 |
|---|---|
| ID | 记录唯一标识 |
| 模块 Key | 所属模块标识 |
| 字段 Key | 字段名称 |
| 字段类型 | 字段数据类型（int / bool / string） |
| 必填 | 是否必填字段 |
| 默认值 | 字段默认值 |
| 操作 | 编辑、删除操作 |

### 6. 表格数据内容（共 5 条）

| ID | 模块 Key | 字段 Key | 字段类型 | 必填 | 默认值 |
|---|---|---|---|---|---|

### 7. 分页控件
- 总记录数：**共 5 条**
- 每页条数：10 条/页
- 当前页码：第 1 页

## 预期行为

1. **删除操作触发**：用户在 Schema 列表中点击某条记录的"删除"按钮，确认删除后执行删除请求
2. **成功提示展示**：删除成功后，页面顶部立即显示绿色提示条，文案为"删除成功"
3. **列表自动刷新**：删除完成后，Schema 列表自动重新加载数据，已删除的记录不再出现在列表中
4. **分页更新**：如果当前页数据变化，分页信息和总条数同步更新
5. **无残留状态**：删除操作不会留下加载中的 spinner 或错误状态
