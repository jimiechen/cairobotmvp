## 预期行为

1. **文件上传**：用户通过拖拽或点击方式选择 `test_strings.csv` 文件
2. **参数填写**：填写有效的目标 Pack ID
3. **执行导入**：
   - 点击"开始导入"按钮
   - 前端将文件以 multipart/form-data 格式发送到后端导入 API
   - 后端解析 CSV 内容并逐条写入数据库
4. **成功响应**：
   - 后端返回 200 及导入统计信息（成功/失败/总数）
   - 前端显示绿色"导入完成"提示
   - 展示已上传文件名供确认
5. **数据验证**：导入完成后，对应语言包下的字符串列表应包含新导入的数据
