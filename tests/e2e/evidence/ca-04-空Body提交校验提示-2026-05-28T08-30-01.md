## 页面描述
在新增 Schema 弹窗中 **未填写必填字段** 直接点击"确定"按钮后，系统触发的 **前端表单校验错误提示** 状态。

## 关键元素

### 1. 校验错误提示信息
弹窗中显示 **红色边框和红色文字** 的错误提示，具体如下：

#### 错误项 1：模块 Key 字段
- **输入框边框**：**红色高亮边框**，表示该字段存在校验错误
- **当前值**：显示占位符文本 `如：app.server`（或为空）
- **错误提示文字**（位于输入框下方）：**"模块Key 不能为空"**
- **文字颜色**：**红色**
- **必填标识**：左侧有红色 * 号标记

#### 错误项 2：字段 Key 字段
- **输入框边框**：**红色高亮边框**，表示该字段存在校验错误
- **当前值**：显示占位符文本 `如 timeout, port`（或为空）
- **错误提示文字**（位于输入框下方）：**"字段Key 不能为空"**
- **文字颜色**：**红色**
- **必填标识**：左侧有红色 * 号标记

### 2. 其他表单字段状态
以下字段因非必填或已填写，**未触发校验错误**：

| 字段名称 | 当前值/状态 | 是否显示错误 |
|---------|------------|:-----------:|
| 字段类型 | `字符串 (string)` | ❌ 否 |
| 是否必填 | 否 (未选中) | ❌ 否 |
| 默认值 | 占位符 `请输入默认值` | ❌ 否 |
| 校验规则 JSON | 示例占位符 | ❌ 否 |
| 描述 | 占位符 `字段用途说明` | ❌ 否 |

### 3. 弹窗操作按钮
- **取消按钮**：正常显示，可点击关闭弹窗
- **确定按钮**：仍可点击，但会再次触发校验

### 4. 背景页面
Schema 列表页面处于遮罩禁用状态，可见列表数据但无法交互。

## 预期行为

1. **前端校验机制**：
   - ✅ 点击"确定"按钮时，前端应先执行表单数据校验
   - ✅ 必填字段（带 * 号）未填写时，应阻止表单提交
   - ✅ 错误字段应以视觉方式明确标识（红色边框 + 错误文字）
   - ✅ 错误提示文字应清晰说明具体的校验失败原因

2. **校验规则实现细节**：
   - 模块 Key（moduleKey）：非空校验，不允许空白字符串
   - 字段 Key（fieldKey）：非空校验，不允许空白字符串
   - 字段类型（fieldType）：下拉选择框，通常有默认值或必选校验
   - 校验应支持实时校验（失焦时）和提交时校验两种模式

3. **用户体验要求**：
   - 错误提示应在对应字段下方紧邻显示，便于用户定位问题
   - 错误提示应有合理的持续时间，直到用户修正错误或关闭弹窗
   - 多个字段同时出错时，应全部展示错误信息
   - 修正错误后，错误提示应及时消失

4. **安全性考虑**：
   - 前端校验不应作为唯一的数据合法性保障
   - 后端接口也应进行相同的数据校验，防止绕过前端直接调用 API

## 测试结论
✅ **通过** - 前端表单校验功能正常工作，必填字段空值提交时正确显示错误提示。
