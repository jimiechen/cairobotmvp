# IA-12 回滚语言包成功后状态

## 测试用例编号

IA-12（回滚语言包 - 成功后状态）

## 截图时间

2026-05-28 08:32:53

## 页面描述

执行语言包回滚操作成功后的页面状态。页面顶部显示绿色的"回滚成功"操作反馈提示，回滚目标版本号字段显示为 3，表示当前语言包已成功回滚到版本 3。

## 关键元素

| 元素 | 描述 | 状态/值 |
|------|------|---------|
| 成功提示条 | 页面顶部绿色 Toast 提示横幅 | **"回滚成功"** |
| 回滚表单区域 | 包含回滚相关字段的表单 | 正常显示 |
| 语言包ID/选择器 | 指定要回滚的语言包 | 已选有效值 |
| 回滚到版本输入框 | 目标版本号字段 | **值为 3** |
| 回滚按钮 | 触发回滚操作的按钮 | 可点击 |

## 预期行为

1. **触发条件**：用户在回滚表单中填写有效的目标版本号并点击"回滚"按钮
2. **请求发送**：
   - 发送 POST/PUT 请求到回滚 API
   - 请求体包含语言包标识和目标版本号
3. **成功响应处理**：
   - 后端返回 200 或类似成功状态码
   - 前端显示绿色"回滚成功"提示
   - 提示持续数秒后自动消失
4. **数据一致性**：
   - 语言包当前版本已回退到指定版本（截图显示为版本 3）
   - 关联的字符串数据与目标版本一致
5. **审计日志**：回滚操作应记录操作人、时间、源版本、目标版本等信息

## 关联测试场景

- 前置条件：参见 [ia-13-空版本号回滚警告提示](./ia-13-空版本号回滚警告提示.md) 的初始状态
- 业务含义：回滚功能是发布流程的重要安全机制，允许在发布问题版本后快速恢复
