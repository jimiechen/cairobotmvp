# IA-19 无效 Pack ID 导出错误提示

## 测试用例编号

IA-19（CSV 导入导出 - 源 Pack ID 为空的校验错误）

## 截图时间

2026-05-28 08:33:57

## 页面描述

CSV 导出操作页面中，用户未填写"源 Pack ID"字段时，系统触发表单前端校验，在字段下方显示红色错误提示信息"请输入源 Pack ID"，阻止无效导出请求的提交。

## 关键元素

| 元素 | 描述 | 状态 |
|------|------|------|
| 页面标题 | "CSV 导出"或类似标题 | 正常显示 |
| 源 Pack ID 输入框 | **必填字段**，指定要导出的源语言包标识 | **为空** |
| Pack ID 错误提示 | 红色文字校验错误信息 | **"请输入源PackID"** |
| 导出 CSV 按钮 | 触发导出操作的按钮 | 已点击触发校验 |

## 预期行为

1. **触发条件**：用户点击"导出 CSV"按钮时，源 Pack ID 字段值为空
2. **前端校验拦截**：
   - 不发送 HTTP 请求到后端
   - 在源 Pack ID 字段下方显示红色错误文案
3. **错误信息**：
   - 文案："请输入源PackID"
   - 样式：红色字体，位于字段正下方
4. **防御深度**：
   - 前端：表单级校验拦截空值提交
   - 后端：即使绕过前端也应拒绝缺少 Pack ID 参数的请求（返回 400）
5. **恢复方式**：填写有效的源 Pack ID 后错误消失，按钮可正常执行导出
