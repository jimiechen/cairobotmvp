# Adapter Module

## 概述

协议适配模块负责 Protobuf 和 Tars 协议之间的转换，以及统一错误码的处理。

## 职责

- Protobuf 请求转换为 Tars 请求
- Tars 响应转换为 Protobuf 响应
- 错误码转换（Tars 错误 → Protobuf 错误）
- 协议兼容性处理

## 文件说明

| 文件 | 说明 |
|------|------|
| proto_adapter.go | Protobuf 与 Tars 协议转换 |
| result_adapter.go | 结果和错误码转换 |

## 错误码映射

| Tars 错误 | Protobuf 错误码 | 说明 |
|-----------|----------------|------|
| 0 | 10200 | 成功 |
| -1 | 10400 | 参数错误 |
| -2 | 10401 | 未授权 |
| -3 | 10403 | 无权限 |
| -4 | 10404 | 未找到 |
| -5 | 10409 | 冲突 |
| -6 | 10504 | 超时 |
| -7 | 10503 | 服务不可用 |
| -8 | 10429 | 请求过多 |
| 其他 | 10500 | 内部错误 |
